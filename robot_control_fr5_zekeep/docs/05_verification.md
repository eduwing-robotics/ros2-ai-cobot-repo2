## Actual — 팀 통합

| 항목 | 상태 |
|---|---|
| 서버 → `/cell/status` 텔레메트리 수신 (서버측 telemetry_gateway 구독) | 확인 |
| `/fr5/joint_states` → Unity 디지털 트윈 | 확인 |
| 글로벌캠 → Unity 관제 (UDP 21030, 1280×960) | 확인 |
| 서버 `ExecuteTask` → 벽 삽입 파이프라인 자동 실행 | **미완** — 오케스트레이터(계약)와 `house_cycle`(삽입)이 아직 분리돼 있고, `part_code/slot → 벽 색` 매핑 테이블이 없음 |
| 서버 즉시 정지 → 로봇 정지 | **미완** — `immediate_pause_enabled=False`, ABORT 는 phase 경계에서 반영. 사이클 도중 정지는 콘솔 `abort`(브리지 stop 직결)만 가능 |

## 사고와 교훈 (실기에서 확인된 것만)

| 사고 | 원인 | 조치 |
