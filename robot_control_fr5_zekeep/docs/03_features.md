# 03. 주요 기능

## 1. 벽 삽입 파이프라인 (`src/fr5_cycle/house_cycle.py`)

한 장의 벽에 대해 아래 단계를 순서대로 실행합니다. 각 단계는 게이트를 지나야 다음으로 넘어갑니다.

| 단계 | 하는 일 | 게이트 · 자동복구 |
|---|---|---|
| ① BASE | 빈손으로 관측자세 → 밑판 기둥 색점 4점으로 위치·회전, ArUco 고정 자로 카메라 복귀 오차 보정 | 4점 미검출 시 제자리 노출 탐색 (로봇 이동 없음) |
| ② RACK | 랙 관측 → 벽 색점(양끝 + 가운데)으로 파지점 → 파지 → 들어올림 | 벽 길이 ±2 %, 가운데 점 미검출 시 노출 사다리 → 그래도 없으면 ±12 mm 재탐색 |
| ③ CARRY | 안전 고도(z650) 경유 → 슬롯 목표 위 정렬 높이(z_seat + HOVER_DZ) | 슬롯 기준 + 베이스 이동분 |
| ④ ALIGN | 든 벽 색점 ↔ 밑판 지정 기둥의 관계를 기준과 비교해 XY(·rz) 수렴 | 최소 실행 이동량 아래는 명령 안 함, 지정 점 미검출 시 노출 사다리, 실패 시 기준 자리 폴백 |
| ⑤ DESCEND | 3 mm 단계 하강 + 든 벽 점 밀림 감시 | 밀림 감지 시 정지 · 25 mm 후퇴 (하강 시작은 사람이 확인) |
| ⑥ SEAT / RELEASE | 기둥 점으로 안착 판정 → 개방 → 상승 | 판정 불가 시 목표 z 도달로 완료 처리(기준 승격 없음) |

- 집 타입 A/B 는 `config/house_a`, `config/house_b` 의 기준으로 전환 (`switch_house`)
- 삽입 순서: 외벽 blue → yellow → red → red_s → 내벽 (A: blue_in, yellow_in / B: red_in)
- 성공 시 기준 승격(`promote_ref`)은 지정 기둥·환산자·노출 등 설정 키를 보존한 채 측정치만 갱신

## 2. 비전 보정 (`hover_align.py`, `place_calc.py`, `pillar_dots.py`)

- **자코비안 실측** — 로봇을 조그시켜 픽셀 변화를 재서 `Jinv`(mm/px)를 만듭니다. 자세(관측·랙·정렬 높이)마다 따로 가지고, 높이 차이는 축척으로 보정합니다. 부호는 Δ≠0 에서 검증합니다.
- **같은 프레임 상대 정렬** — 기준 촬영 때의 "지정 기둥 ↔ 든 벽 점" 픽셀 관계를 저장하고, 지금 관계와의 차이만 로봇 이동으로 바꿉니다. 기둥 지정(`pillar_pick.json`)이 없으면 저장을 거부해 옆 벽의 점이 기준에 섞이지 않게 합니다.
- **예측 이동 매칭** — 기준 자리와 지금 자리가 다르면 기둥은 화면에서 그만큼 밀려 보이므로, 이번 계산 목표를 원점으로 예측 위치 근처에서만 찾습니다.
- **같은 점 증명** — 조명이 달라 점 면적이 기준과 다르면, 여러 노출에서 중심이 3 px 안에 모이는지로 같은 점임을 확인한 뒤 진행합니다(면적 게이트 완화가 아니라 증거 추가).
- **카메라 역할** — 손목 D435 가 XY·rz 를 조종하고 보조 카메라는 참고 측정만 기록합니다(실측: 밑판 항은 두 캠이 0.39 mm 로 일치, 든 벽 항만 갈림 → 불일치는 정지 사유가 아님).
- **화이트밸런스 고정** — WB 5500 K 에서 파랑 점 면적 1823 → 258 로 붕괴. 런처 · 자동복구 데몬 · 사이클 시작 점검 3중으로 4600 K 고정.
- **유령점 배제** — 진짜 점(S255)과 반사상(S103~164)을 채도로 분리하고, 반사상은 색이 아닌 배열 기하로 배제.

## 3. 카메라를 힘 센서로 (`place_calc.descend_monitored`)

3 mm 씩 내려가며 그리퍼가 문 벽의 색점이 화면에서 밀리는지 봅니다. 벽이 기둥에 걸리면 로봇은 내려가는데 벽은 못 내려가므로 픽셀 이동으로 나타납니다.

| 층 | 수단 |
|---|---|
| 1차 | 하강 중 벽 점 밀림 감시 — 단계별 · 누적 픽셀 임계 초과 시 그 자리 정지 · 후퇴 |
| 2차 | 그리퍼 실측값 감시 — 파지 직후 값에서 벌어지면 놓치는 중 |
| 3차 | 충돌 레벨 + 페이로드 등록(0.7 kg) |
| 4차 | J6 대회전 봉인 — 컨트롤러 동결의 진범 |

한계: 기둥이 그리퍼 마찰보다 먼저 부러지면 픽셀에 변화가 없어 원리적으로 무력합니다(9/2 파손으로 확인). 정공법은 F/T 센서 또는 순응(RCC) 장치입니다.

## 4. 로봇을 의심하는 검증

| 명령 | 실제 이동 | 실행률 |
|---:|---:|---:|
| 0.3 mm | 0 | 0 % |
| 0.5 mm | 0.505 mm | 100 % |

브리지는 실행 여부와 무관하게 `started` 로 답합니다. 최소 유효 명령(자세별 0.6~1.15 mm)을 실측해 검증 기준 4곳을 정정했고, 그 아래로는 명령하지 않고 한계 수렴으로 처리합니다.

## 5. 완성품 출하 (`fork_carry.py`)

완성된 집을 포크 손잡이째 출하지로 옮깁니다. 손잡이 파란 점으로 XY 를 보정(축척은 z440 에서 5 mm 왕복 실측)하고, 운반 내내 그리퍼 값을 감시해 벌어지면 즉시 정지합니다. 그리퍼 규칙이 벽과 반대(벌어지면 빠짐)라 개방은 두 자리에서만 허용합니다.

## 6. ZeKeep PLC 제어 (`src/zekeep/`)

- `zk_profiles.py` — 포트 · 조그 비트 · 자세 DB 단일 출처 (1호기/2호기 개체차 흡수)
- `zk_startup.py` / `zk_home_run.py` — 전원 후 원점 복귀 (D76 비유지)
- `zk_jog.py` / `zk_move.py` / `zk_pose.py` — 조그 · 자세 이동 · 잔차 다듬기
- `zk_refine.py` — 2 % 저속 왕복으로 잔차 수렴 (관성 0.17°)
- `zk_zline.py` / `zk_vlift.py` — 역기구학으로 105 mm 수직 직선 (반경 편차 ±2 mm)
- `zk_carry.py` / `zk_pickplace.py` — 흡착 반송 사이클
- `zk_ros2_node.py` — ROS 2 노드 (joint_states, MoveIt2 트윈)
- `zk_safety.py` / `zk_a1snap.py` — 안전 한계 · A1 정밀 스냅
- `zkbot2_control/` — 2호기 실측 세팅 · 흡착 밸브 시험 기록

## 7. 운영 콘솔 (`src/console/bf2_robot_console.html`)

이종 로봇 2종을 한 화면에서: 조그 · 시퀀스 기록/재생 · 실시간 관절 트윈 · 카메라 4대 동시 감시 · 사이클/리코더 탭 전환 · 단계별 기준점 오버레이. 모든 실기 시험이 이 콘솔 위에서 이루어졌습니다.
