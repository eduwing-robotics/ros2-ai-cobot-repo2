# ZKBOT-301ED 2호기 흡착·밸브 실측 시험 기록

작성일: 2026-08-08  
대상: ZKBOT-301ED 2호기  
범위: Y14 진공 펌프 및 Y15 밸브의 실제 흡착·해제 동작 확인

> 이 문서는 2호기에서 실제 물체(지갑)를 사용해 확인한 I/O 시험 기록이다. 관절은 시험 내내 이동시키지 않았으며, 모든 시험 종료 시 Y14/Y15 출력 OFF를 확인했다.

## 1. 시험 전 상태

- 관절: A1/A2/A3 원점 상태
- 비상정지: X5 OFF
- 리밋: X0/X1/X2 OFF
- PLC 통신: 정상
- 시험 물체: 지갑
- 안전 조치: 조합 시험 중 사용자가 지갑을 손으로 지지

## 2. 출력 매핑 결론

| PLC 출력 | 실측 역할 | 근거 |
|---|---|---|
| `Y14` | 진공 펌프 | Y14 단독 ON에서 지갑 흡착 성공 |
| `Y15` | 흡착 해제용 배기/릴리즈 밸브 | Y14 ON 상태에서 Y15 ON 시 지갑 흡착이 풀림 |

Y15 단독 펄스에서도 밸브의 작은 클릭 소리가 들렸다. 따라서 Y15은 PLC 출력과 실제 솔레노이드 밸브 연결 모두 확인됐다.

## 3. 실제 시험 기록

### 3.1 Y14 펌프 단독 시험

명령:

```bash
python3 zk_io.py pump-pulse --seconds 2
```

조건과 결과:

- Y14 펌프: 2초 ON
- Y15 밸브: OFF 유지
- 사용자 관찰: 지갑이 흡착판에 정상적으로 붙음
- 관절 이동: 없음
- 종료 확인: Y14/Y15 모두 OFF

### 3.2 Y15 밸브 단독 시험

명령:

```bash
python3 zk_io.py valve-pulse --seconds 1
```

조건과 결과:

- Y14 펌프: OFF 유지
- Y15 밸브: 1초 ON
- 사용자 관찰: 밸브 쪽에서 작은 클릭 소리
- 종료 확인: Y14/Y15 모두 OFF

### 3.3 펌프·밸브 조합 시험

명령:

```bash
python3 zk_io.py pump-valve-sequence --seconds 1
```

실행 순서:

1. Y14 펌프 ON, Y15 OFF로 2초간 흡착 생성
2. Y14는 유지한 채 Y15 밸브 ON 1초
3. 종료 시 Y14/Y15 모두 OFF

결과:

- Y14만 ON인 구간: 지갑 흡착
- Y15 ON 구간: 지갑 흡착 해제 확인
- 결론: Y15은 해제/배기 역할

## 4. 현재 I/O 시험 명령

```bash
cd /home/yr/SimFirst/zkbot2_control

# 펌프 단독: 0.1~5초만 허용
python3 zk_io.py pump-pulse --seconds 2

# 밸브 단독: 펌프 OFF 상태에서만 시험
python3 zk_io.py valve-pulse --seconds 1

# 흡착 후 해제 시험: 물체는 반드시 손으로 지지
python3 zk_io.py pump-valve-sequence --seconds 1
```

`zk_io.py`는 성공·실패·Ctrl+C와 관계없이 마지막에 Y14/Y15를 모두 OFF로 해제한다. 관절 조그와 원점복귀 명령은 포함하지 않는다.

## 5. 주의사항 및 남은 검증

- 흡착판 위 물체는 항상 사람이 지지한 상태에서 처음 시험한다.
- Y15을 켜면 물체가 즉시 떨어질 수 있으므로, 로봇이 물체를 든 상태에서 무심코 실행하지 않는다.
- 지갑 한 종류만 확인했다. 실제 자재의 재질, 표면 평탄도, 무게별 흡착력은 별도 시험이 필요하다.
- 진공 센서나 흡착 성공 피드백은 아직 확인하지 않았다.
- 생산 공정에서는 단순 시간 지연만으로 성공을 판단하지 말고, 향후 비전·센서·FMS 상태검증과 결합해야 한다.
