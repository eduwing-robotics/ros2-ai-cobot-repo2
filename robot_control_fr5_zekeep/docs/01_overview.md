# 01. 프로젝트 개요

## 배경

AI 기반 조립식 주택 자동화 공장은 자재 검사 → 팔레트 운반 → 밑판·벽체·지붕 조립 → 조립 결과 검사 → 완성 주택 출고까지를
하나의 생산 시스템으로 연결합니다. 관리자는 음성으로 생산을 요청하고, 관제 화면(Unity)에서 공정·로봇·재고·검사 결과를 확인합니다.

이 문서가 다루는 **로봇셀 파트**는 그 가운데 "조립"을 실물 로봇으로 수행하는 영역입니다.

| 로봇 | 담당 공정 |
|---|---|
| FR5 6축 협동로봇 | 외벽 4장 · 내벽 1~2장 파지 → 운반 → 밑판 슬롯 삽입, 완성 주택 포크 이송(출하) |
| ZeKeep 3축 로봇 ×2 | 밑판 · 지붕 흡착 반송 (PLC 직접 제어) |

## 문제 정의

조립식 주택 모형의 벽은 밑판 기둥 사이 홈에 끼우는 구조입니다. 밑판이 조금만 틀어져도 벽 밑동이 기둥에 걸립니다.
그런데 이 밑판은 **매 사이클 다른 로봇(ZeKeep)이 새로 놓습니다.** 지그가 없는 것이 아니라 지그를 둘 수 없는 조건입니다.

| 조건 | 결과 |
|---|---|
| 밑판 위치가 사이클마다 mm 단위로 바뀐다 | 티칭한 절대좌표로는 매번 다시 가르쳐야 한다 |
| 벽은 랙에서 집을 때마다 그리퍼 안 자세가 달라진다 | 파지 오차가 정렬 이동량에서 시차로 증폭된다 |
| 힘·토크 센서가 없다 | 접촉을 감지할 물리적 수단이 없다 |
| ZeKeep 은 제조사 문서·SDK 가 없다 | 펜던트 수동 조작만 가능, 반복 정밀도 3.1 mm |

## 개발 목적 (설계 목표)

1. **밑판이 틀어져도 따라가는 삽입** — 절대좌표 대신 "든 벽 ↔ 밑판" 상대 정렬
2. **사람 개입은 하강 확인 1회로 축소** — 나머지 단계는 카메라 측정으로 자동
3. **사고를 막는 게이트 체계** — 게이트에 걸리면 완화하지 않고 검출 보강 또는 사람에게 인계
4. **로봇이 바뀌어도 사는 상위 코드** — 작업 · 순서 · 하드웨어 3계층 분리

## 담당 영역의 역할

서버(FMS)가 `"외벽 한 장 설치"` 라는 작업을 보내면, 그것을 실물 로봇의 0.1 mm 단위 동작으로 바꾸는 계층 전부입니다.

- 서버 인터페이스 계약(ROS 2 Action / Service / Topic) 설계·구현 — 일시정지·재개 포함
- 셀 오케스트레이터 — task → phase 시퀀스, 상태기계, 오류코드
- 벽 삽입 파이프라인 — 밑판 측정 · 랙 파지 · 운반 · 정렬 · 하강 · 안착 · 출하
- 자체 비전 보정 — 카메라 4대(손목 D435 · 보조 · 측면 · 글로벌)로 파지·삽입 오차를 잡는 보정 계통. 팀 비전 파트의 YOLO 품질검사와는 별개
- 운영 콘솔 — 이종 로봇 2종을 한 화면에서 조그 · 시퀀스 기록/재생 · 관절 트윈 · 카메라 감시
- ZeKeep PLC 제어 — MODBUS-RTU 직결, 역기구학 유도, 반복 정밀도 개선

## 최종 결과 요약

- 벽 5장 연속 삽입 5/5, 하강 중 막힘 0건
- 파지 재현 오차 1.7 mm → 0.13 mm, 정렬 수렴 잔차 0.41 mm
- −97° · 35 mm 비틀린 밑판에서 삽입 성공 (절대좌표 사용 구간 0)
- ZeKeep 반복 정밀도 3.1 mm → 0.55 mm, 105 mm 직하강 반경 편차 ±2 mm
- 완성품 출하 이송 도달 오차 ≤ 0.05 mm
