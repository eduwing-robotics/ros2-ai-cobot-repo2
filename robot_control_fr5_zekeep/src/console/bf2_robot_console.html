ZK 링크 길이 (트윈용, mm)

ZK 링크 길이는 실측값이 없어 임의 기본값. 트윈 형상만 영향, 명령값엔 무관. zk_profiles.py 또는 실측 후 교체.

ZK 조인트 한계 (°)

실측 한계(2026-08-06, zk_safety 와 동일). ZK 는 원점 0°가 상한 — 음(−)방향으로만 가동. UI 는 이 범위 밖 목표를 차단.

로봇 배치 (트윈, mm / °)
